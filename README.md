# Comparative Analysis of ML Regression Models for Urban Transit Time Prediction
## Dataset Overview (`real_uk_transit_dataset_COMPLETE.csv`)
- **Records:** 4,931 empirical point-to-point journeys across Greater London.
- **Sources:** Transport for London (TfL) Unified Journey API (UK Open Government Licence) & UK ONS Postcode Directory (`pgeocode`).
- **Features:** 5 Greater London logistics hubs, 100 destination postcodes, 6 daily dispatch windows, Haversine urban road distance (`1.28x` circuity), transit modes, leg counts, and active disruptions.
